# BookOasis 소설넷 평점 플러그인

소설넷의 평균 평점과 최고·최저 평점 리뷰를 BookOasis 작품 메타데이터에 적용합니다.

## 설치

1. [ssn_rating.zip](./ssn_rating.zip)을 받습니다.
2. 압축 안의 `ssn_rating` 폴더를 BookOasis `plugins/metadata/` 아래에 배치합니다.
3. BookOasis를 재시작하고 환경설정에서 `소설넷 평점` 플러그인을 활성화합니다.

상세 동작과 설정은 [플러그인 문서](./ssn_rating/README.md)를 참고하세요.
