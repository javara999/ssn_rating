# 소설넷 평점 플러그인

소설넷의 공개 작품 페이지에서 평균 평점과 최고 평점 리뷰를 가져와 BookOasis 메타데이터에 적용합니다.

## 동작

1. BookOasis 메타정보 검색에서 `소설넷 평점`을 선택합니다.
2. 작품명을 검색하고 제목·작가·평점을 확인합니다.
3. 결과를 선택하면 평균 평점과 내용이 있는 최고 평점 리뷰를 조회합니다. 내용이 있는 리뷰가 없으면 리뷰 항목은 생략합니다.
4. BookOasis의 `score`와 `summary`만 갱신합니다. 표지·작가·출판사·ISBN은 변경하지 않습니다.

BookOasis의 평점은 100점 정수이므로 소설넷 5점 평점을 `round(평점 × 20)`으로 저장합니다. 정확한 5점 평점과 평가 인원은 작품 설명의 `[소설넷 평점]` 블록에 표시됩니다. 다시 적용하면 기존 소설넷 블록을 교체하며 중복해서 추가하지 않습니다.

## 설치

```text
plugins/metadata/ssn_rating/
├── __init__.py
├── ssn_rating.py
├── VERSION
└── README.md
```

폴더를 BookOasis의 `plugins/metadata/` 아래에 배치하고 서버를 재시작한 뒤 환경설정의 플러그인 목록에서 활성화합니다.

저장소: `https://github.com/javara999/ssn_rating`

## 설정

- `MAX_RESULTS`: 최대 검색 결과 수, 기본 10
- `REVIEW_MAX_LENGTH`: 리뷰별 최대 저장 글자 수, 기본 1000
- `PRESERVE_SUMMARY`: 기존 작품 설명 보존, 기본 활성화
- `TIMEOUT`: HTTP 요청 제한 시간, 기본 15초
- `CACHE_TTL`: 동일 페이지 캐시 시간, 기본 600초

## 제약

- 소설넷 공식 API가 아닌 공개 HTML과 JSON-LD를 사용하므로 사이트 구조가 변경되면 파서 수정이 필요합니다.
- `robots.txt`의 요청 간격을 따라 외부 요청 사이에 최소 10초 간격을 둡니다. 검색 직후 적용하면 남은 요청 간격만큼 기다릴 수 있습니다.
- 최고 평점 리뷰는 평점 내림차순 결과에서 본문이 존재하는 첫 리뷰를 사용합니다.
- BookOasis의 `summary` 블록에는 정확한 평점과 리뷰만 저장합니다.
